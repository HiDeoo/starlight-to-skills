To prominently recommend an agent skill and show how to install it, use the `<SkillCallout>` component.

import { Preview } from '@hideoo/starlight-plugins-docs-components'

<Preview>

<Fragment slot="preview">
  <SkillCallout skill="upgrade-v2-to-v3">

    Install this skill and ask your agent to migrate your project from v2 to v3.

  </SkillCallout>
</Fragment>

</Preview>

The component requires Astro's [`site` option](https://docs.astro.build/en/reference/configuration-reference/#site) to be set to your site's deployed URL.

## Import

```tsx
import SkillCallout from 'starlight-to-skills/components/SkillCallout.astro'
```

## Usage

Recommend a skill prominently using the `<SkillCallout>` component.
A `<SkillCallout>` requires a [`skill`](#skill) prop matching the [name](/skill-definition/) of an approved skill.

<Preview>

```mdx
import SkillCallout from 'starlight-to-skills/components/SkillCallout.astro'

<SkillCallout skill="upgrade-v2-to-v3" />
```

<Fragment slot="preview">

<SkillCallout skill="upgrade-v2-to-v3" />

</Fragment>

</Preview>

### Add a description

Add a description to provide additional context or instructions.

<Preview>

```mdx {5-6}
import SkillCallout from 'starlight-to-skills/components/SkillCallout.astro'

<SkillCallout skill="upgrade-v2-to-v3">

We have a skill specifically designed to help you migrate your project to v3.
Install it before asking your agent to perform the migration.

</SkillCallout>
```

<Fragment slot="preview">

<SkillCallout skill="upgrade-v2-to-v3">

We have a skill specifically designed to help you migrate your project to v3.
Install it before asking your agent to perform the migration.

</SkillCallout>

</Fragment>

</Preview>

### Use custom titles

Override the default title by using the `title` attribue.

<Preview>

{/* prettier-ignore */}
```mdx /title=.*"/
import SkillCallout from 'starlight-to-skills/components/SkillCallout.astro'

<SkillCallout
  skill="upgrade-v2-to-v3"
  title="Use your agent to migrate to v3"
/>
```

<Fragment slot="preview">

<SkillCallout skill="upgrade-v2-to-v3" title="Use your agent to migrate to v3" />

</Fragment>

</Preview>

### Add follow-up instructions

Add follow-up instructions displayed below the installation command by using the `footer` slot.

<Preview>

{/* prettier-ignore */}
```mdx {7-9}
import SkillCallout from 'starlight-to-skills/components/SkillCallout.astro'

<SkillCallout skill="upgrade-v2-to-v3">

Install the skill specifically designed to help you migrate your project to v3.

<Fragment slot="footer">
  Then ask your agent to perform the migration.
</Fragment>

</SkillCallout>
```

<Fragment slot="preview">

<SkillCallout skill="upgrade-v2-to-v3">

Install the skill specifically designed to help you migrate your project to v3.

<Fragment slot="footer">Then ask your agent to perform the migration.</Fragment>

</SkillCallout>

</Fragment>

</Preview>

## `<SkillCallout>` Props

The `<SkillCallout>` component accepts the following prop:

### `skill`

**Required**  
**Type:** `string`

The [name](/skill-definition/) of the skill to recommend.
